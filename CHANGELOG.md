# Changelog

## [1.0.0] - 2026-10-16

### Added

- Colored sticky notes on macOS 13 and later, with Arabic right-to-left and English left-to-right text.
- Ten light colors and ten dark colors. The default color is `#F3C15B`.
- Per-note pin, lock, font size, and a menu-bar pin icon with no Dock icon.
- Open at login from Settings.
- Local JSON storage with an atomic replace and a backup file.
- Unit tests, `./scripts/build-app.sh`, and a 512×512 repository image at `docs/pinFiy-512.png`.
- MIT license.
