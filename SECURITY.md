# الأمان

pinFiy لا يتصل بالشبكة. الملاحظات تبقى في ملفات محلية على جهازك. لا تفتح قضية عامة فيها نص ملاحظة أو مسار منزلي كامل.

إذا وجدت ثغرة، أبلغ عنها بشكل خاص عبر Security Advisories في GitHub بعد نشر المستودع. قبل النشر، أرسل التفاصيل إلى مشرف المشروع مباشرةً ولا تضعها في قضية عامة.

# Security

pinFiy does not connect to the network. Notes stay in local files on your Mac. Do not open a public issue that contains note text or a full home-directory path.

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |

## Reporting a vulnerability

After this repository is published, report a vulnerability through GitHub Security Advisories (Private vulnerability reporting). Before that, send the details directly to a project maintainer and do not file a public issue.

Please include:

- pinFiy version and macOS version
- the affected area, such as storage, the menu bar, or window level
- steps that show the problem, using sample text rather than real notes

Give the maintainers time to confirm and ship a fix before any public write-up.
