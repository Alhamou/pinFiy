# الخصوصية

pinFiy تطبيق محلي. لا حساب، ولا تحليلات، ولا شبكة. النص واللون والمكان وحجم الخط وحالة الدبوس والقفل تُحفظ في:

`~/Library/Application Support/pinFiy/notes.json`

وتُنسخ نسخة صالحة إلى `notes.json.bak` قبل الاستبدال. حذف التطبيق لا يحذف هذا المجلد تلقائيًا. يمكنك حذف المجلد بنفسك لإنهاء البيانات.

خيار «فتح عند تسجيل الدخول» يسجّل التطبيق لدى macOS عبر Login Items. لا يُرسل شيء خارج الجهاز.

# Privacy

pinFiy is a local app. There is no account, no analytics, and no network access. Text, color, frame, font size, pin state, and lock state are stored at:

`~/Library/Application Support/pinFiy/notes.json`

A valid copy is kept at `notes.json.bak` before replacement. Deleting the app does not delete that folder. Remove the folder yourself to erase the data.

Open at login registers the app with macOS Login Items. Nothing is sent off the machine.
